# Archived design material

These directories preserve earlier proposals and planning notes for provenance.
They are not imported by the MCP server, not active skill instructions, and not
proof that a described feature has been implemented or verified.

The current design is documented in the parent architecture and API development
guides. Runtime implementation lives in cst_api, api_library, harness and mcp.

User projects, simulation data and vendor reference collections are not archived
here and were not moved as part of this reorganization.
